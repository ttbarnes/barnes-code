
# Barnes Code website

Built with [Next.js](https://nextjs.org/)

##  Prerequisite

- Node version 18.7.0 or higher with corresponding npm.
- Run `npm install` in the root directory.

## Tech stack

- Node, NPM
- Next.js, React
- Jest
- ESlint
- framer-motion

## Running locally

```bash
npm run dev
```

### Execute unit tests

```shell
npm run test
```

### Execute linting

```shell
npm run lint
```
